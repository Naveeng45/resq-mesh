Strands SDK

Pattern 1 — Structured Extraction

from strands import Agent
from strands.models.bedrock import BedrockModel

agent = Agent(
    model=BedrockModel(model_id="us.amazon.nova-lite-v1:0", ...),
    system_prompt="Extract facts only. Never decide.",
    structured_output_model=Mission,   # Pydantic model → guaranteed schema
)

result = agent("We need Thursday coverage at Riverside — van driver, packer, site lead")
mission = result.structured_output   # Mission(destination=..., requirements=[...])

structured_output_model guarantees the LLM returns a valid Mission.
Missing facts are null, not hallucinated.

Strands SDK

Pattern 2 — Tool-Calling Advisor

advisor = Agent(
    model=BedrockModel(...),
    system_prompt="Never decide yourself. Call tools and report their output.",
    tools=[assess_incident, get_available_resources, get_resources_by_capability],
)

# Coordinator asks a plain-English question
answer = advisor("Can Riverside Eastside open Thursday?")
# → Agent calls assess_incident → CP-SAT solver runs → plain-English verdict

The Advisor is a ReAct agent with 3 tools.
It orchestrates and explains. The deterministic tools decide.
