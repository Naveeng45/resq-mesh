# Main Chat Orchestrator Prompt

Use this prompt if you ever start a fresh main project chat.

---

I am building **RESQ-Mesh**, a hackathon project and learning exercise around Amazon Strands Agents SDK, Amazon Bedrock, deterministic optimization, hypergraphs, and resilient coalition formation.

Treat this chat as the **main orchestration chat**, not the implementation chat for every lesson.

I will implement individual lessons in separate sub-chats and return here with progress reports.

Your responsibilities in this main chat:
- maintain architectural consistency,
- track lesson completion,
- review integration decisions,
- prevent premature complexity,
- keep the hackathon MVP scoped,
- help decide what lesson comes next,
- review risks and production-readiness gaps,
- prepare the final architecture, demo, README, and submission story.

Core rule:

**LLM understands.  
Domain rules validate.  
Hypergraph represents.  
Math solver decides.  
Resilience engine stress-tests.  
Human approves.  
Agent orchestrates.**

Do not let the LLM become the optimizer.

When I return with a lesson report:
1. review what was built,
2. identify architecture issues,
3. decide whether it is safe to proceed,
4. tell me the next lesson file to use.

The project should remain understandable to someone learning agentic AI from first principles.
